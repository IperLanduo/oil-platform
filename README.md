# 精油生理數據整合平台（第一版）使用說明

這份說明假設你**從來沒寫過程式**。照著一步一步做就可以跑起來。

---

## 0. 這個平台在做什麼？（先懂目的）

你有兩種資料：

| 資料 | 從哪來 | 裡面有什麼 |
|---|---|---|
| 手錶 CSV | ASUS Watch | 每次量測的時間、血壓（收縮壓/舒張壓）、心跳、壓力指數、RMSSD |
| 腦電波 Excel | 腦波儀，已整理好 | 每天「擦精油前（pre）」和「擦後 0/5/10/15/20 分鐘」的腦波指標 |

你想回答的問題是：**擦精油之後，血壓有沒有變低？人有沒有變放鬆？**

要回答這個問題，平台做五件事：

1. **讀檔**：把 CSV、Excel 讀進來。
2. **清理**：把量測失敗的資料挑掉（不然會讓結果變不準）。
3. **分組**：分出「擦精油前」和「擦精油後」。
4. **畫圖**：讓你用眼睛看變化。
5. **統計**：用數學判斷「這個變化是真的，還是只是剛好」。

## 1. 第一次要做的準備（只要做一次）

### 1-1. 安裝 Python

Python 是一種程式語言。我們的平台是用 Python 寫的，所以電腦要先裝 Python 才能執行。

1. 打開 https://www.python.org/downloads/
2. 下載最新版（3.11 以上都可以）並安裝。
3. **Windows 使用者**：安裝第一個畫面，一定要勾選「**Add Python to PATH**」。
   （意思是：讓電腦在任何地方都找得到 Python。）

### 1-2. 打開「終端機」

終端機是一個可以打字下指令給電腦的視窗。

- **Windows**：按開始鍵，搜尋「命令提示字元」或「PowerShell」，打開它。
- **Mac**：按 ⌘ + 空白鍵，搜尋「終端機」(Terminal)，打開它。

### 1-3. 走到平台的資料夾

假設你把 `oil-platform` 資料夾放在桌面。在終端機輸入（輸入完按 Enter）：

```
cd Desktop/oil-platform
```

`cd` 的意思是「change directory，換到某個資料夾」。

### 1-4. 安裝平台需要的套件

套件 = 別人寫好的工具，我們直接拿來用（例如畫圖工具、讀 Excel 的工具）。
`requirements.txt` 這個檔案列了所有需要的套件。輸入：

```
pip install -r requirements.txt
```

（Mac 如果說找不到 pip，改用 `pip3 install -r requirements.txt`。）

看到一堆文字跑完、最後沒有紅色 ERROR，就是成功了。

## 3. 平台的五個分頁，各在做什麼

### ① 資料總覽與清理
- 上面四個數字：原本幾筆、清理後剩幾筆、刪掉幾筆、找到幾場實驗。
- 血壓折線圖：藍 = 收縮壓、橘 = 舒張壓。
- 點「看被移除的資料和原因」可以逐筆檢查刪掉的是哪些、為什麼。

**為什麼要清理？** 範例檔中有 30 筆的「壓力指數」是空白、RMSSD 是 0。
RMSSD 是心跳之間的變化量，活人幾乎不可能是 0，所以這通常代表**那次量測失敗**。
你也會發現這些失敗的量測，血壓常常偏低（像 109/61），跟前後的 123/72 差很多，
留著會讓結果被拉偏。左邊可以取消勾選，看看保留它們會怎樣。

### ② 手錶：每場擦前 vs 擦後
手錶的量測分兩種（看 CSV 的「量測類型」欄）：
- **129** = 手錶自己自動量，大約每小時一次（包括睡覺時）。
- **1** = 有人手動按下去量。

範例中的手動量測都是**一群一群**出現（約 6 筆、每筆隔 10 分鐘），
所以平台推測：**一群 = 一場精油實驗**，第 1 筆是擦精油前，後面是擦精油後。

你要做的事：在表格裡**勾選哪幾場有用精油**。
沒用精油的場次（對照組）把勾拿掉，平台會分開計算。

### ③ 手錶：時段比較（例如睡眠）
如果你想知道「晚上擦精油睡覺，夜裡血壓/RMSSD 有沒有比較好」：
在表格填入有擦精油的時段（開始時間、結束時間），平台會把這段時間的自動量測，
跟其他時間比較。勾「只看睡覺時段」就只比較 22:00–07:00。

### ④ 腦電波：擦前 vs 擦後
- 灰線 = 每一天；藍線 = 所有天的平均（直直的小線段是「標準差」，代表每天差多少）。
- 下面的表把每個時間點都和 pre 比。
- **Meditation** 是放鬆程度，**Attention** 是專注程度。範例中 **Pressure 正好 = 100 − Meditation**，所以兩個其實是同一個資訊，不用重複解讀。

### ⑤ 同一天合併比對
把同一天的手錶實驗和腦電波排在一起。對齊方法（目前是**假設**）：
手錶那場第 1 筆 ↔ 腦波 pre，第 2 筆 ↔ 0 min，第 3 筆 ↔ 5 min……
範例中手錶是 8/3–8/14、腦波是 7/27–8/3，**只有 8/3 一天重疊**，所以現在只能列表格。

## 4. 看懂統計表（最重要的觀念）

**成對比較**：同一場實驗（或同一天）的「擦前」和「擦後」配成一對來比。
這樣比較公平，因為每個人每天的狀態本來就不同，我們只看「同一次裡面變了多少」。

表格欄位：
- **組數 n**：有幾對可以比。越多越可靠。少於 3 對就不做檢定。
- **平均變化(後−前)**：負的 = 擦後變低（血壓變低是你希望看到的；RMSSD、Meditation 則是變高比較好）。
- **p 值**：假如精油其實**完全沒效**，光靠運氣看到這麼大差異的機率。
  - p < 0.05：這麼大的差異「不太像只是運氣」，通常就說有顯著差異。
  - p ≥ 0.05：**不代表精油沒效**，只代表「目前的資料還不足以下結論」。
- **t 檢定** 和 **Wilcoxon**：兩種算 p 值的方法。資料少的時候，Wilcoxon 比較不怕極端值。兩個結論一致時比較可信。

**範例資料目前的結果**：手錶 11 場、腦波 8 天，各項指標的 p 值都大於 0.05，
也就是**目前還看不出確定的效果**。這很正常：資料量還小，而且還缺少「沒擦精油」的對照組。

## 5. 檔案說明

| 檔案 | 用途 |
|---|---|
| `app.py` | 網頁畫面、畫圖、統計 |
| `loaders.py` | 讀檔和清理（每段都有中文註解） |
| `requirements.txt` | 需要安裝的套件清單 |
| `sample_data/` | 你給的兩個範例檔 |

建議閱讀順序：先讀 `loaders.py`（比較短、比較單純），再讀 `app.py`。
